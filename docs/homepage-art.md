# Homepage artwork

## Cinematic implementation

The approved homepage uses `public/images/roulette-hero.webp`. The game uses
`public/images/colonnade.webp`. Both are generated photographs converted to WebP
at quality 85. The previous assets remain available for rollback.

The live wheel is an SVG component with the existing 38-pocket order, exact
roulette colors, and the existing result-driven rotation. Generated mockup
numbers are not used as game data. No spin, settlement, or confirmation rules
were changed by the cinematic redesign.
